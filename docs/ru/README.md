Основные документы — английские; [docs/ru](README.md) — русское зеркало. Перед каждым заголовком в обоих языках стоит маркер `<!-- section: <id> -->` с id, взятым из английского заголовка; зеркало использует те же id в том же порядке, и `tests/test_docs.py` это проверяет.
