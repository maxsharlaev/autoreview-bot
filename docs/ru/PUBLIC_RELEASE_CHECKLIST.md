# Чеклист публичного релиза

Основной язык документации — английский. Русский перевод — в [docs/ru](README.md).

Выполните эти проверки перед публичным релизом.

| Проверка | Критерий релиза |
| --- | --- |
| Исходники, документация, примеры и ассеты наблюдаемости | Нейтральные имена и примеры данных; проверьте файлы релиза на чувствительную информацию |
| Локальная конфигурация | `.env`, `config.yaml`, приватные ключи и локальные промпты не попадают в Git и контекст сборки Docker |
| Креды | Прогоните отдельный сканер секретов по файлам релиза и ротируйте любые найденные креды |
| Лицензирование | Включите Apache-2.0 и проверьте уведомления сторонних зависимостей и ассетов |
| CI и политика контрибуции | Проходят Ruff, тесты и сборка образа; добавьте проверки, запланированные в [ROADMAP.md](ROADMAP.md) |
| Production-настройки по умолчанию | Порты базы и Redis закрыты, метрики ограничены, подпись webhook обязательна, прежде чем рекомендовать прямую доставку webhook |
